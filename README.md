# বাংলা পঞ্জিকা (Android)

পশ্চিমবঙ্গের বাংলা ক্যালেন্ডার — ঐতিহ্যবাহী লাল, ক্রিম ও সোনালি নকশা।

## নির্বাচিত পদ্ধতি
- অঞ্চল: পশ্চিমবঙ্গ (প্রাথমিক রেফারেন্স কলকাতা)
- পঞ্জিকা-সিদ্ধান্ত: গুপ্তপ্রেস / সূর্যসিদ্ধান্ত
- বাংলা তারিখের বর্তমান রূপান্তরটি আনুমানিক; এটি যাচাইকৃত গুপ্তপ্রেস গণনা নয়।

## বর্তমান ফিচার
- মাসভিত্তিক ইংরেজি ক্যালেন্ডার
- দিন নির্বাচন, আজকের দিনে ফেরা, শেয়ার
- বাংলা তারিখের প্রাথমিক রূপান্তর
- তিথি, নক্ষত্র ও সূর্যোদয়-সূর্যাস্তের তথ্য যাচাই না থাকলে স্পষ্টভাবে অপেক্ষমাণ দেখায়

## গুরুত্বপূর্ণ সীমাবদ্ধতা
গুপ্তপ্রেসের প্রকাশিত দৈনিক তিথি, নক্ষত্র, যোগ, করণ, রাহুকাল, সূর্যোদয়-সূর্যাস্ত এবং শুভ মুহূর্তের নির্ভুল ডেটা বা পূর্ণ সূর্যসিদ্ধান্ত গণনা এখনও যুক্ত হয়নি। তাই এই সংস্করণ পূজা, ব্রত বা শুভ মুহূর্ত নির্ধারণের জন্য ব্যবহার করবেন না।

## APK build
এই repository-তে GitHub Actions workflow আছে। `main` branch-এ push করলে Android debug APK build হবে এবং Actions run-এর Artifacts থেকে ডাউনলোড করা যাবে।

লোকালি Android Studio-তে project folder খুলে Gradle Sync করুন, তারপর **Build → Build APK(s)** নির্বাচন করুন.
